🛡️ ResolveX - Smart Complaint Management & Grievance Redressal Portal

ResolveX is a modern, interactive, single-page web application designed for civic and public grievance redressal. It bridges the communication gap between citizens, support operators, and department managers with real-time status tracking, SLA monitoring, and automated lifecycle visualization.

✨ Key Features

🧑‍💼 Multi-Role Workspace Switcher:

Citizen View: Submit grievances, track live ticket status, view resolution timelines, post feedback, and rate completed resolutions.

Support Admin Mode: Reassign complaints to engineers, update ticket statuses, manage work logs, and inspect SLA targets.

Department Manager Dashboard: Access high-level analytics, operational workloads, and performance charts.

📊 Real-Time Analytics & Metrics (Chart.js):

Category breakdown chart (Infrastructure, Sanitation, Billing, Tech, Civic).

Monthly complaint filing trends.

Status resolution success rates.

⏱️ SLA & Lifecycle Progress Tracker:

Interactive visual timeline showing step-by-step progress from submission to resolution.

SLA target timers and priority tags (Urgent, High, Medium, Low).

🔍 Global Search & Dynamic Filtering:

Search by Ticket ID, Title, Category, or Location in real-time.

Filter ticket queues by category, urgency, or current state.

🛠️ Tech Stack

HTML5 & CSS3

Tailwind CSS (Utility-first responsive design & dark theme)

Vanilla JavaScript (ES6+) (State management, filtering, dynamic modal rendering)

Chart.js (Data visualization & analytics)

FontAwesome 6 (Vector iconography)

🚀 How to Run Locally

Clone or Download the Repository:

git clone https://github.com/your-username/complaint-management-portal.git
cd complaint-management-portal


Launch the Application:

Simply double-click index.html to open it in any web browser (Chrome, Edge, Firefox, Safari).

Alternatively, open the folder in VS Code and run with the Live Server extension.
